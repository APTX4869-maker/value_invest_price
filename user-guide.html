Page 1

你打开网站后，就按这条线走

这份指南只服务一个目标：让你不用记住所有功能，也能完成一次完整的公司研究。每次不知道下一步做什么，就回到这条流程。

发现雷达 → 研究队列 → 公司档案 → 估值 → 同行 → 备忘录 → 历史
1
不知道研究谁时先去发现雷达，从股票池里挑线索。
2
有兴趣但没结论时放进研究队列，给它安排下一步动作。
3
准备认真看一家公司时进入公司档案，按结论、业务、估值、同行、备忘录顺序看。
不要把这个网站当成很多页面的集合。把它当成一个研究流程：先发现，再筛选，再形成自己的判断。
  • 第一次用：按 1 到 8 页走一遍。
  • 平时用：直接从研究队列开始。
  • 结果异常：去历史和设置排查数据源。
Page 2

发现雷达：你不知道看谁时，从这里开始

打开“发现雷达”后，先选股票池，再扫描。它的作用不是给结论，而是帮你把一堆公司缩小成几个值得继续看的候选。

1
先选池子默认用 S&P 500；想看科技成长时切 QQQ；自己有名单就用自定义池。
2
再看“为什么排前面”重点读估值、质量、护城河、数据缺口这些理由，不要只看分数。
3
只把有兴趣的加入队列先加 3 到 5 个，不要一次塞太多，否则后面很难研究完。

你在这里只做一件事

判断“这家公司值不值得进入下一步”。不要在发现雷达里纠结最终目标价，也不要把排名当成买卖建议。

Page 3

研究队列：这是你平时最常打开的首页

如果你已经有一批想看的公司，平时不要从发现雷达开始，而是直接进研究队列。这里告诉你每家公司现在卡在哪一步。

1
先看状态列候选只是想看；初筛通过才值得继续；深度研究中才需要认真补资料。
2
再看下一步动作如果下一步是空的，先补一句，例如“刷新数据”“检查同行”“写备忘录”。
3
每天只推进少数几家公司选一家公司点进档案，不要同时打开太多研究线。

队列不是收藏夹

它应该像你的研究待办板。每一家公司都要能回答：我为什么关注它，现在研究到哪一步，下一步要补什么。

Page 4

公司档案：进入一家公司后，先看总判断

点进公司档案后，不要马上翻所有标签页。先看顶部的一页纸结论：系统现在认为它便宜、合理、偏贵，还是数据不足。

1
先看当前判断便宜、合理、偏贵、不确定，这决定你后面要不要继续花时间。
2
再看业务和财务先搞懂它怎么赚钱，收入、利润、现金流是不是有质量。
3
最后再看证据和 AI 初稿SEC 和 AI 研究助手只是帮你整理材料，最终判断要写进备忘录。

你在这里的目标

用 3 到 5 分钟判断：这家公司是值得深挖，还是先放回队列以后再看。

Page 5

估值模型：用它检查价格隐含的预期

进入估值页后，不要把系统数字当答案。你要看的是：当前股价需要什么样的增长、利润率和估值倍数才能成立。

1
先点重新计算或刷新如果数据过旧，先刷新公司数据；如果只是改参数，就重新计算。
2
再看目标区间和假设来源重点看系统用了历史数据、手动输入、同行，还是外部数据源。
3
最后看敏感项如果结果很离谱，先查增长、利润率、同行倍数和前瞻 EPS。

你应该怎么读结果

估值不是投资建议。它是一个假设检查器：帮你看当前价格是不是已经把很乐观的未来提前算进去了。

Page 6

同行比较：用来防止你被单家公司数字带偏

看完估值后，再看同行。这里不是为了找一堆公司，而是确认：这家公司跟真正可比的公司相比，到底贵不贵、质量差在哪里。

1
先看核心同行只有核心同行会影响估值判断；外部候选只是参考，不能直接混进去。
2
再删掉不合适的公司行业不一样、商业模式不一样、周期属性不一样，就不要放进核心同行。
3
最后刷新比较数据用同行倍数、质量分、FCF yield 来校验估值结论是否合理。

你要特别注意

同行越多不代表越准确。宁愿只保留 3 到 6 个真正相近的公司，也不要让一长串错误同行污染判断。

Page 7

投资备忘录：这是你真正形成结论的地方

看完业务、估值和同行后，不要只停留在脑子里。把判断写进备忘录，后面复盘时才知道当时为什么这么想。

1
先写一句当前结论例如：偏贵但值得跟踪、合理但缺少安全边际、便宜但数据质量不足。
2
再写核心假设列出你相信它的原因，比如增长来源、利润率改善、行业周期、护城河。
3
最后写反证清单明确什么情况出现时，你要承认自己看错了。

备忘录比自由笔记重要

自由笔记可以补充细节，但结构化备忘录才是复盘入口。每次形成判断，都应该保存一个版本。

Page 8

历史和设置：出问题时先来这里排查

平时你不需要频繁打开设置页。但如果刷新失败、估值异常、数据来源缺失，先来这里检查 API key、默认参数和历史快照。

1
先看历史快照对比之前的合理中枢、当前价、判断变化，确认是不是数据变化导致。
2
再看数据源配置FMP、Alpha Vantage、Finnhub、FRED、LLM 配置都在设置里。
3
最后再回到公司档案配置修好后，重新刷新公司数据，再回估值页看结果。

你的日常使用顺序

平时：研究队列 → 公司档案 → 估值/同行 → 备忘录。遇到异常：历史和设置 → 刷新数据 → 再看估值。
